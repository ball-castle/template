# 个人铜牌算法与题型手册实施计划

> 按用户明确执行指令推进；使用 executing-plans 与 dispatching-parallel-agents 工作流，不再要求用户批准计划。

**目标：** 以用户验证使用过的代码为主，补齐 ACM02/02A/02B 的高频知识、模型推导、调用和打印检索。

**架构：** 原成果保留。每个新增或个人化模块具有规范源码、来源记录、独立测试；模型卡引用模块。先生成赛前短补丁，再整合 V2。两个原 PR 增量提交。

**技术：** GNU++20、Python、JSON/Markdown、python-docx、Word PDF 导出、Poppler。

**规格：** 本目录 AUTHORING_CONTRACT.md 与用户 ACM02、02A、02B 全文；后续明确纠正优先。

## 工作单元

- 基线与个人风格：核对两个 PR，逐项登记32正式/32旧源/思维卡；统计 cf 源文件并精读代表性代码。产出 CURRENT_COVERAGE_AUDIT、PERSONAL_CODE_STYLE、来源映射。
- 赛前运行与 STL：原 read 直接收录、输出/精度/三角、容器算法、堆与有序集合、字符串 Trie、MEX/博弈。每个例子进入测试。
- XOR 专题：核验指定6份训练源与题意；前缀/贡献/构造/二进制Trie/图约束/线性基/Nim，生成个人补题记录。
- DP：从数位/序列/树/状压原代码提取，补齐15类状态识别、推导、初值、遍历、可运行代码和对照测试。
- 数据结构个人主版本：原Fenwick/线段树最小修复；覆盖13类Node维护与调用；测试赋值0、标记先后、负数子段、非负频率第k，保留双版时共用oracle。
- 图与数学基础：原树存储、DSU、BFS/DFS、Dijkstra/LCA个人接口；补网格/多源/01BFS/Floyd/染色/直径与基础数论几何。
- 通用模型与导航：区间操作严格证明及构造、贪心/构造/二分/贡献/枚举搜索/回文等，HOW_TO_THINK 与题型索引。
- 补丁先交付：仅选择已验证高频卡/代码生成真实DOCX/PDF并全页检查。
- V2与覆盖：整合规范源码、卡片与旧模块，生成机器检查覆盖表、来源表、打印页码；完整测试、配对哈希、逐页渲染。
- 独立审查与GitHub：修复重要发现；先推template原PR分支，再更新cf gitlink，fresh clone验证并更新两个PR描述。绝不自动合并。

## 必须重点验证

- 计数/容量/下标合法、多测清空，原read只在用户约定的普通输入范围使用。
- 混合lazy的赋值0和操作组合顺序，空区间与全负最大子段。
- DP未达状态和重复计数，digit DP含0与区间端点，SG要求有限无环正常规则。
- XOR无符号位宽/Trie空树与容量/图约束矛盾/线性基与Trie语义差异。
- 旧四份文件不变，新Word/PDF逐行代码对应，模块依赖、实际页码与矩阵匹配。
